======================================================================
LoRa CAMPUS MONITOR - MASTER CONNECTION LIST (ALL REQUIRED CONNECTIONS)
======================================================================

One list of every connection needed to build the complete system:
  1 x Main node (Raspberry Pi 3B+ + Ra-02)       -> section 1  (IDs M01..)
  2 x Field node (ESP32 + Ra-02 + 4 sensors)     -> section 2  (IDs N-01..)
      The field-node circuit is built TWICE: tick [N1] and [N2].

Columns:  [check]  ID  FROM -> TO  WIRE COLOUR  NEED
          second line: signal | software setting that uses the pin | note

Need:  Required      = must be fitted
       If pin exists = only if your breakout board has that pin
       Recommended   = strongly advised (noise filter)
       Optional      = only if the feature is used
       Not connected = leave the pin open

Same data for Excel / printing: master_connection_list.csv
Full explanations + diagrams: 01_/02_/03_*.txt and 3d/ viewer.

1. MAIN NODE - RASPBERRY PI 3B+  (tick when done)
-------------------------------------------------

  >> Power & storage
  [ ]  M01  5 V / 2.5 A adapter              -> Pi micro-USB power port        -        Required
          5 V supply | Do not power the Pi from the GPIO header
  [ ]  M02  32 GB microSD (Raspberry Pi OS)  -> Pi microSD slot                -        Required
          Storage | Bookworm or newer

  >> LoRa Ra-02
  [ ]  M03  Pi pin 1 (3.3 V)                 -> Ra-02 VCC                      Orange   Required
          3.3 V | NEVER pin 2 or 4 (5 V)
  [ ]  M04  Pi pin 6 (GND)                   -> Ra-02 GND                      Black    Required
          GND
  [ ]  M05  Pi pin 23 (GPIO11 SCLK)          -> Ra-02 SCK                      Yellow   Required
          SPI SCK | config.toml spi_bus=0
  [ ]  M06  Pi pin 21 (GPIO9 MISO)           -> Ra-02 MISO                     Green    Required
          SPI MISO | config.toml spi_bus=0
  [ ]  M07  Pi pin 19 (GPIO10 MOSI)          -> Ra-02 MOSI                     Purple   Required
          SPI MOSI | config.toml spi_bus=0
  [ ]  M08  Pi pin 24 (GPIO8 CE0)            -> Ra-02 NSS                      White    Required
          SPI chip select | config.toml spi_device=0
  [ ]  M09  Pi pin 22 (GPIO25)               -> Ra-02 RESET                    Brown    Required
          Reset | config.toml reset_pin=25
  [ ]  M10  Pi pin 18 (GPIO24)               -> Ra-02 DIO0                     Gray     Required
          RX-done interrupt | config.toml dio0_pin=24
  [ ]  M11  100 nF ceramic capacitor         -> Ra-02 VCC <-> GND              -        Required
          Decoupling | As close to the module as possible
  [ ]  M12  10 uF capacitor                  -> Ra-02 VCC (+) <-> GND (-)      -        Required
          Decoupling | Observe polarity
  [ ]  M13  433 MHz antenna (IPEX cable)     -> Ra-02 antenna socket           -        Required
          RF | Fit BEFORE power-on
  [ ]  M14  Ra-02 DIO1..DIO5                 -> -                              -        Not connected
          Leave open

  >> Network
  [ ]  M15  Pi Ethernet port (or built-in Wi-Fi) -> Router / switch -> laptop      -        Required
          LAN | config.toml [web] port=5000 | Dashboard http://<pi-ip>:5000

4. GOLDEN RULES
---------------
  1. Ra-02 VCC = 3.3 V only (Pi pin 1 / ESP32 3V3). Never 5 V.
  2. ESP32 inputs <= 3.3 V. Measure the MQ-135 junction before GPIO34.
  3. Antenna on every Ra-02 BEFORE power-on.
  4. One common GND inside each unit. The units are NOT wired together.
  5. Same radio settings on all three modules (433 MHz, SF7, BW125, CR4/5, sync 0x12, CRC on).
