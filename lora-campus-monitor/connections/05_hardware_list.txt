Complete system = 1 x MAIN NODE (Raspberry Pi) + 2 x FIELD NODE (ESP32).

Columns:
  MAIN  = quantity for the main node
  NODE  = quantity for ONE field node (built twice)
  SPARE = recommended spares
  BUY   = TOTAL to buy = MAIN + 2 x NODE + SPARE
  Need  = Required / Recommended / Optional / Future
  Second line = specification / buying note -> what it is used for

Same list for Excel / Google Sheets (with empty price columns):
  hardware_list.csv
Connection IDs (M.., N-..) refer to 04_master_connection_list.txt.

BUYING CHECKS (avoid the common mistakes)
------------------------------------------------------------------------------
  [ ] LoRa modules, antennas and pigtails are ALL 433 MHz (Ra-02), not 868/915.
  [ ] Sensor module says BME280 (humidity), not BMP280.
  [ ] Sound module gives an ANALOG output (AO) and works on 3.3 V.
  [ ] ESP32 board is the 30-pin DevKit V1 (pin map in 02_field_node_1_esp32.txt).
  [ ] Ra-02 adapter PCB matches the Ra-02 footprint (16 half-holes).
  [ ] USB cable is a DATA cable.
  [ ] Node adapters are regulated 5 V (measure: 4.75-5.25 V).
  [ ] 433 MHz use complies with local rules (India: 433-434.79 MHz, low power).
